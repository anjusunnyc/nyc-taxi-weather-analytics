# Project Report

Store the final project report, presentation notes, methodology, analytical assumptions, and supporting documentation here.

Key caveats to retain in reporting:
- Realtime weather is scheduled 15-minute micro-batch ingestion, not event-by-event streaming.
- Current weather is mapped to historical taxi-impact rules; it does not measure live taxi speed or demand.
- Snow results have limited historical support and should be interpreted cautiously.
- Fare and demand findings are associations, not causal claims.
- Tipping analysis is restricted to credit-card trips.
